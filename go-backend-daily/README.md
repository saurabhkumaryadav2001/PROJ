# Go Backend Daily Learning

Daily Go curriculum from fundamentals to production backend. Every day: clear explanations, runnable examples, practice tasks, interview questions, and PDF notes.

- Day 01: Go foundations, packages, main, variables, types, zero values, constants, fmt
- Day 02: Functions, parameters, return values, scope, errors
- Day 03: Control flow, loops, switch
- Day 04: Arrays, slices, maps
- Day 05: Structs, methods, pointers
- Day 06: Interfaces and composition
- Day 07: Error handling patterns
- Day 08: Packages, modules, dependency management
- Day 09: JSON and file I/O
- Day 10: HTTP server and REST APIs
- Day 11: Middleware, routing, request validation
- Day 12: PostgreSQL and SQL transactions
- Day 13: Context, cancellation, timeouts
- Day 14: Goroutines, channels, synchronization
- Day 15+: testing, Docker, config, logging, auth, observability, CI/CD, project build

Daily lessons are sequential. Complete exercises before moving forward.
